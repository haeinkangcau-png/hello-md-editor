# 1. 시스템 개요

이 문단은 H1 섹션(`# 1.`)과 첫 H2(`## 1.1`) 사이에 두는 "섹션 개요"입니다. 해당 섹션 하위 항목들의 상세 패널 상단에 회색 박스로 표시됩니다.

## 1.1 기본 기능

### 개요

- 불릿 리스트와 **굵게**, *기울임*, `인라인 코드` 를 사용할 수 있습니다.
- `## N.M` 항목 하나하나가 좌측 목차와 가운데 리스트에 카드로 노출됩니다.
- 번호 목록도 됩니다:
  1. 첫 번째 단계
  2. 두 번째 단계

### 지원 항목

| 항목 | 설명 | 상태 |
| --- | --- | --- |
| 기능 A | 표로 정리합니다 | 정상 |
| 기능 B | 셀에 `미정의` 라고만 쓰면 태그로 표시됩니다 | 미정의 |

## 1.2 확인 필요 표기

- 미확정 사항은 문장 끝에 [확인 필요] 를 붙입니다. 주황 태그가 생기고, 좌측 항목 카드에 "확인 필요" 배지가 달립니다.
- 예시: 세션 타임아웃 정책은 기본 30분으로 예정 [확인 필요]

# 2. 참조와 링크

## 2.1 다른 섹션 참조

→ 섹션 1.1 기본 기능 참조

위처럼 `→ 섹션 N.M ...` 로 시작하는 줄은 상세 패널에 보라색 "참조" 노트로 표시됩니다.

## 2.2 외부 문서 링크

외부 문서는 두 가지 방식으로 연결합니다.

@@외부정의서

- 줄 단독으로 쓴 `@@파일명` 은 상세 패널 하단에 **링크 카드**로 표시됩니다. (위 `@@외부정의서`)
- 문장 안에서는 인라인으로 @@{외부정의서} 처럼 씁니다.
- 실제 URL은 맨 끝 `# 99. 링크관리` 표의 파일명과 매칭되어 연결됩니다.

## 2.3 미정의 항목

미정의 — 이 항목은 아직 정의되지 않았습니다. 줄 시작을 `미정의 —` 로 쓰면 상세 패널에 미정의 블록으로 표시됩니다.
